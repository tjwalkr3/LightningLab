Using the Search Bar in .NET MAUI with an External API

In this demo, we're going to learn how to use a search bar in a .NET MAUI app to make searches in an API.

Maui's built-in search bar is extremely simple and powerful. It quickly combs through data to help the user find what they need. It has a built-in search button, clear button, and a binding to the Enter key.

First, make a new .NET MAUI project. Create a folder for Views and ViewModels. Move the MainPage view into the views folder and create a corresponding ViewModel for it. Add the appropriate route to AppShell.json and set the MainPageViewModel as the binding context for MainPage. First, we are going to add a DTO class to our app. For convenience of this demo, I will add it under the ViewModel. 

public class StreamModel
{
    [JsonPropertyName("name")]
    public string Name { get; set; } = string.Empty;

    [JsonPropertyName("url_resolved")]
    public string Url { get; set; } = string.Empty;
}

Next, we will open the ViewModel and add an ObservableCollection of StreamModels and a string to hold the search query.

public partial class MainPageViewModel : ObservableObject
{
    [ObservableProperty]
    private string _searchQuery = string.Empty;

    public ObservableCollection<StreamModel> AllStreamsList { get; } = [];
}

Now, we will add a method to the ViewModel that will get the items that we want to render. In this case, we will be getting them from the Radio Browser API. 

private static async Task<List<StreamModel>> Search(string query)
{
    List<StreamModel> streams = [];
    HttpClient _httpClient = new()
    {
        BaseAddress = new Uri("https://at1.api.radio-browser.info")
    };

    using HttpResponseMessage response = await _httpClient.GetAsync($"/json/stations/byname/{query}?order=clickcount&limit=10");
    if (response.IsSuccessStatusCode)
    {
        var result = response.Content.ReadAsStringAsync().Result;
        streams = JsonSerializer.Deserialize<List<StreamModel>>(result) ?? [];
    }

    return streams;
}

Now that we can get servers from the API, let's add a RelayCommand that can add the StreamModels to the ObservableCollection.

[RelayCommand]
private async Task SearchStreams()
{
    AllStreamsList.Clear();

    List<StreamModel> searchResults = string.IsNullOrWhiteSpace(SearchQuery)
        ? []
        : await Search(SearchQuery);

    foreach (var stream in searchResults)
    {
        AllStreamsList.Add(stream);
    }
}

After this, go to MainPage.xaml and delete everything inside the VerticalStackLayout. Add a SearchBar to MainPage.xaml. This search bar's text field is bound to the SearchQuery observable property and the SearchStreamsCommand that we created eaarlier. 

<SearchBar Placeholder="Search streams..."
           Text="{Binding SearchQuery, Mode=TwoWay}"
           SearchCommand="{Binding SearchStreamsCommand}"
           FontSize="18"
           Margin="0,10" />

Lastly, we need to add a CollectionView to display our servers

<CollectionView ItemsSource="{Binding AllStreamsList}">
    <CollectionView.ItemTemplate>
        <DataTemplate>
            <VerticalStackLayout>
                <Label Text="{Binding Name}"
                       FontAttributes="Bold"
                       FontSize="18"
                       Margin="0,0,0,8" />
                <Label Text="{Binding Url}"
                       FontSize="14"
                       Margin="10,0,0,8" />
            </VerticalStackLayout>
        </DataTemplate>
    </CollectionView.ItemTemplate>
</CollectionView>

You should now be able to run the app and search for internet radio stations using the search bar.
